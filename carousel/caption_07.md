# 캐러셀 #06 「남자에게 버림받는 법」 최종본 12장 (c07v3_slide_01~12)

## 캡션
```
남자에게 버림받는 법, 간단해요.

1. 그의 마음을 확인받기 전엔 절대 안심하지 마라.
2. 서운한 건 말하지 말고, 알아채길 기다려라.

나머지 5개는 넘기면서 세어보세요.
마지막에 당신의 유형이 나옵니다. 안정형? 흔들림형? 불안형?

남자는 이런 여자가 싫어서 떠나는 게 아니에요.
'나는 늘 부족한 사람'이라고 느낄 때 떠나요.
그리고 이건 거의 다 불안에서 나와요. 당신 잘못이 아니에요.

친구한테 보내고 "너는 무슨 형이야?" 물어보세요.
남자친구에게는 마지막 장만 보내주세요.

📕 불안할 때 남자가 실제로 하는 생각은 「남자들끼리 하는 말」 1·2권에 적었습니다.
프로필 링크에서 무료로 받아보세요.

#연애심리 #남자심리 #불안형애착 #애착유형 #연애고민 #남자들끼리하는말
```

## 고정 댓글
```
무슨 형 나왔어요? 유형만 남겨주세요 🙂
(이건 '여자 탓'이 아니라, 불안이 사랑을 밀어내는 방식에 대한 이야기예요)
```

## 올린 직후
- 스토리에 11장(유형 결과)을 올리고 퀴즈 스티커: "나는? 안정형 / 흔들림형 / 불안형"
- 48시간 뒤 저장 대비 공유 비율 확인. 공유가 저장의 절반을 넘으면 이 구조(결과 유형 + 대신 전하는 한 장)를 C 시리즈 기본으로.
