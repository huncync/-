# 캐러셀 #07 「남자가 헤어지기 전에 하는 말들」 (c08_slide_01~11)

## 기존 게시물과 겹치지 않게 고른 말
- #02·릴스에서 쓴 말(바빴어 / 생각할 시간이 필요해 / 넌 좋은 사람이야 / 우리 천천히 가자 / 나중에 연락할게 / 지금은 연애할 상황이 아니야)은 전부 뺐습니다.
- #03 카톡 말(ㅇㅇ, 자니?, 나중에 얘기하자 등)과 #05 행동 6개(기억 못 함, 휴대폰, 통화, 혼자 정함, 피곤함, 스토리)도 겹치지 않습니다.
- 새 말 6개: 요즘 우리 좀 안 맞는 것 같아 / 네가 하고 싶은 대로 해 / 요즘 나도 나를 잘 모르겠어 / 미안해, 다 내가 잘못했어 / 너한테 부담 주기 싫어 / 넌 나 없어도 잘 지낼 거야

## 팔로우를 위한 새 장치
- 2장: "남자인 제가 직접 말합니다 · 박지훈"
- 11장: 다음 편 예고 「헤어진 남자가 돌아오고 싶을 때 하는 말들」 + "놓치지 않게 팔로우"

## 캡션
```
남자는 끝을 말하기 전에, 몇 달 동안 이런 말을 먼저 해요.

"요즘 우리 좀 안 맞는 것 같아"
"네가 하고 싶은 대로 해"
"너한테 부담 주기 싫어"

나머지 3개는 넘기면서 세어보세요.
마지막 장에 몇 개면 어떤 상태인지 적어뒀어요.

한 마디는 신호가 아니에요.
세 개 이상 겹치면, 그땐 대화할 때예요.

몇 개 들어봤는지 댓글로 숫자만 남겨주세요.
친구한테 보내고 "너는 몇 개야?" 물어보세요.

다음 편은 월요일 밤 9시, 「헤어진 남자가 돌아오고 싶을 때 하는 말들」입니다.
놓치지 않으려면 팔로우해 두세요.

📕 남자가 하는 말의 뜻은 「남자들끼리 하는 말」 1·2권에 적었습니다.
프로필 링크에서 무료로 받아보세요.

#남자심리 #연애심리 #이별 #남자속마음 #연애고민 #남자들끼리하는말
```
