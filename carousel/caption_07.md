# 캐러셀 #06 「남자에게 버림받는 법」 (c07_slide_01~10)

## 캡션
```
남자에게 버림받는 법, 간단해요.

1. 그의 마음을 확인받기 전엔 절대 안심하지 마라.
2. 서운한 건 말하지 말고, 알아서 알아채길 기다려라.
3. 화가 나면 말 대신 침묵으로 벌을 줘라.
4. 그가 해준 것보다 안 해준 것을 먼저 말해라.
5. 다른 남자와 비교해라.
6. 그의 휴대폰, 동선, 인간관계까지 다 알아야 안심해라.
7. 연애를 시작하면 당신의 세계를 전부 그에게 맞춰라.

남자는 이런 여자가 싫어서 떠나는 게 아니에요.
'나는 늘 부족한 사람'이라고 느낄 때 떠나요.

그리고 이 일곱 가지는 거의 다 불안에서 나와요.
당신이 잘못한 게 아니라, 그만큼 불안했던 거예요.

몇 개나 해당됐는지, 댓글로 숫자만 남겨주세요.

📕 남자가 하는 말의 뜻은 「남자들끼리 하는 말」 1·2권에 적었습니다.
프로필 링크에서 무료로 받아보세요.

#연애심리 #남자심리 #불안형애착 #연애고민 #연애 #남자들끼리하는말
```
