# 1:1 채팅 상담 앱

DM으로 오던 상담을 **예약 → 결제 → 정해진 시간에 1:1 채팅**으로 옮기는 웹앱입니다.
휴대폰에서 홈 화면에 추가하면 앱처럼 쓸 수 있습니다.

| 주소 | 누가 |
|---|---|
| `/` | 고객: 상담 소개 → 예약 → 결제 → 채팅방 → 내 상담 |
| `/admin` | 상담사(본인): 시간 열기, 예약·사연 확인, 채팅, 완료·불참 처리, 환불 |

## 고객 흐름
1. 상품(30분/60분)과 열린 시간을 고른다
2. 지금 상황을 적고 필수 동의 3개(의료 아님·민감정보·약관)에 체크
3. 가입(이메일·비밀번호·닉네임) → 결제
4. 시작 10분 전부터 채팅방 입장, 끝나는 시각에 입력이 닫힘 (대화는 계속 볼 수 있음)
5. 시작 24시간 전까지는 '내 상담'에서 직접 취소 → 자동 전액 환불

## 상담사 화면
- **시간 열기**: 요일·시간대를 골라 2주치를 한꺼번에 열거나, 칸을 눌러 하나씩 열고 닫기
- **예정**: 날짜별 예약 목록, 사연, 같은 고객의 이전 상담, 채팅, 완료/불참/환불(부분 환불 가능)
- 새 예약·새 메시지가 오면 소리 + 화면 알림 (🔔 알림 켜기를 누르면 다른 탭에 있어도 알림)
- 휴대폰으로도 받으려면 아래 텔레그램 알림을 켜세요

## 내 컴퓨터에서 실행
Node.js 22.13 이상이 필요합니다.
```bash
cd counsel
npm install
cp .env.example .env     # ADMIN_PASSWORD를 꼭 바꾸세요
npm start                # http://localhost:3000 , 관리자 http://localhost:3000/admin
npm test                 # 예약·결제·채팅·환불 자동 점검
```
처음에는 `PAYMENT_MODE=mock`(가짜 결제)이라 돈이 오가지 않습니다.

## 인터넷에 올리기 (예: Railway, 월 5달러 안팎)
DB가 파일 하나(SQLite)라서 **지워지지 않는 디스크**가 있는 곳이어야 합니다.
1. railway.com 가입 → New Project → Deploy from GitHub repo → 이 저장소 선택
2. 서비스 Settings → Root Directory를 `counsel`로
3. Volume 추가 → 마운트 경로 `/data`
4. Variables에 입력: `ADMIN_PASSWORD`, `DB_PATH=/data/counsel.db`, `PAYMENT_MODE=mock`
5. Settings → Networking → Generate Domain → 나온 주소를 `BASE_URL`에 넣기
6. 인스타 프로필 링크를 그 주소로 바꾸고, DM 자동응답에 "상담은 여기서 예약해 주세요"로 안내

## 실제 결제로 바꾸기
1. 사업자등록(홈택스) → 통신판매업 신고(정부24, 보통 며칠)
2. 토스페이먼츠 가입 → 결제위젯 계약·심사
3. 개발자센터에서 받은 `live_gck_…` / `live_gsk_…` 키를 `TOSS_CLIENT_KEY`, `TOSS_SECRET_KEY`에 넣고 `PAYMENT_MODE=toss`
4. 바꾸기 전에 토스 테스트 키(.env.example에 있는 값)로 `PAYMENT_MODE=toss`를 먼저 켜서 결제창이 뜨는지 확인하세요
5. 이용약관·개인정보 처리방침(고객 화면 맨 아래)에 노랗게 표시된 칸(상호, 사업자번호, 연락처 등)을 채우세요 → `public/app.js`의 `terms()`, `privacy()`

## 휴대폰으로 알림 받기 (텔레그램, 무료)
1. 텔레그램에서 @BotFather → `/newbot` → 받은 토큰을 `TELEGRAM_BOT_TOKEN`에
2. 만든 봇에게 아무 말이나 보낸 뒤 `https://api.telegram.org/bot<토큰>/getUpdates`를 열어 `chat.id` 숫자를 `TELEGRAM_CHAT_ID`에
3. 새 예약·취소가 생기면 텔레그램으로 옵니다

## 바꾸고 싶을 때
- 상품·가격·취소 기한·입장 시각·예약 가능 기간: `config.js`
- 문구·화면: `public/app.js`(고객), `public/admin.js`(상담사), 색·모양: `public/style.css`

## 알아둘 점
- 이 상담은 의료·심리치료가 아님을 예약 단계에서 고지하고 동의를 받습니다. 위급 상황 안내(109·119)가 첫 화면과 예약 화면에 있습니다.
- 상담 내용은 민감정보입니다. 관리자 비밀번호를 길게 정하고, 서버 DB 파일을 함부로 내려받거나 공유하지 마세요.
- 고객 비밀번호 찾기 기능은 아직 없습니다(메일 발송 서비스 연결이 필요). 그 전까지는 문의가 오면 관리자가 확인해 주세요.
