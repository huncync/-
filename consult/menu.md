# 남자 심리 분석 · 상품 메뉴

## A. 남자 심리 분석 · 50,000원
그가 왜 그러는지 알고 싶은 분 (한도: 주 10건)
- 질문지 + 카톡 캡처 10장 + 관상(본인·상대)
- 서면 분석 리포트: 관상으로 본 그의 성향 / 그의 말 번역 / 지금 마음 단계 / 갈등이 반복되는 이유 / 질문 답변
- 추가 질문 1회
- 신청 후 72시간 안에 전달

## B. 심리 분석 + 마음을 움직이는 대본 · 100,000원
그래서 뭐라고 보내야 할지 알고 싶은 분 · 추천 (한도: 주 5건)
- A의 모든 내용
- 상황별 대본 4종: 첫 연락 / 답장이 왔을 때 / 만났을 때·통화할 때 / 반응이 없거나 거절당했을 때
- 보낼 시간대와 하지 말아야 할 말
- 7일 안 피드백 2회 (대본 써보고 생긴 반응까지 · 1회 = 메시지 1개 + 캡처 3장)

## C. 재회·관계 회복 4주 플랜 · 390,000원
한 번의 답이 아니라 끝까지 같이 가고 싶은 분 (한도: 월 3명)
- B의 모든 내용
- 4주 동안 주 1회 상황 점검 + 다음 대본 (총 4회)
- 보내기 전 카톡 첨삭 주 3건
- 연락 타이밍 설계 (언제 보내고, 언제 멈출지)
- 4주 뒤 정리 리포트

## 추가 옵션 (신청자 전용)
- 카톡 첨삭 1건 · 20,000원 — 보내기 전 메시지를 남자 입장에서 검토하고 고쳐드려요
- 카톡 첨삭 3건 묶음 · 50,000원 — 첨삭이 여러 번 필요할 때 · 상담 후 30일 안에 사용
- 추가 질문 1회 · 20,000원 — 분석 받은 뒤 새로 생긴 질문 하나
- 급행 (24시간 안) · +30,000원 — A·B를 24시간 안에 받아보고 싶을 때 · 하루 1건 한정
- 긴급 첨삭 (6시간 안) · 30,000원 — 그에게서 답장·연락이 왔을 때, 6시간 안에 보낼 말을 드려요 · 하루 1건 한정

## 운영 원칙
1. 건당 상품입니다. 시간 단위로 받지 않아요. 고객은 "1시간"보다 "내 상황 결과물"을 사고, 실시간 응대에 묶이지 않습니다.
2. B를 주력으로: A와 C 사이에 두면 B가 "적당한 선택"으로 보여 가장 많이 팔립니다(가격 사다리 효과, 추정).
3. C는 월 3명 한정: 비싸고 적게 팔아야 "제대로 봐준다"는 인상이 생기고, 4주 동안의 변화가 가장 강한 후기가 됩니다.
4. C 39만 원 근거: 첨삭 12건(옵션가로 24만) + B(10만) + 주 1회 점검 4번. 하나씩 사는 것보다 싸서 "이득"이 보이고, 손이 가장 많이 가는 만큼 받습니다.
5. B 피드백은 범위를 정해서: 1회 = 메시지 1개 + 캡처 3장. 범위가 없으면 7일 동안 채팅 상담이 됩니다.
6. 가격 올리는 기준: B가 2주 연속 마감되면 12만~15만 원으로. 가격은 처음부터 맞히는 게 아니라 마감 속도로 정합니다.
7. 옵션은 기존 신청자 전용: 첨삭·추가 질문은 단독 판매하지 않아야 기본 5만 원선이 무너지지 않아요.
8. 오픈 보너스: 할인 대신 "첫 10명 B 신청 시 카톡 첨삭 2건 무료". 가격 기준은 지키고 후기는 빨리 모읍니다.
9. 30일 재신청 혜택(추가 질문 1회): 결과물이 마음에 든 사람이 다음 고민도 맡기게. 원가는 시간 20분 정도.
10. 분리 원칙(11/1): 구독(인스타)과 분석(카카오채널)은 혜택을 섞지 않아요. 3권도 분석에 끼워 주지 않고 따로 팔아요.
11. 결제: 선입금. 환불: 분석 작성 시작 전 전액, 시작 후 불가. 재회 등 결과를 이유로 한 환불은 불가. 이 문구는 안내문에 꼭 넣으세요.
