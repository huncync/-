## 무료 배포 (GitHub Pages)
Settings → Pages → Branch를 이 페이지가 있는 브랜치 / `(root)`로 선택하면
몇 분 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소가 생깁니다.
인스타 링크에 붙일 때는 `?utm_source=instagram`처럼 붙이면 신청서에 유입 경로가 같이 저장됩니다.

## 앱으로 설치 (PWA)
GitHub Pages처럼 `https://` 주소에 올리면 휴대폰에서 앱처럼 설치됩니다.
- **안드로이드(크롬·삼성 인터넷)**: 페이지 맨 아래 "앱으로 설치하기 → 설치" 버튼, 또는 메뉴의 "홈 화면에 추가".
- **아이폰(Safari)**: 공유 버튼 → "홈 화면에 추가" (페이지 맨 아래에 안내가 나옵니다).

설치한 앱으로 들어온 신청은 유입 경로가 `app`으로 저장됩니다.
아이콘은 `icons/`, 앱 이름·색은 `manifest.webmanifest`에서 바꿀 수 있습니다.
`style.css`·`script.js`를 고쳐도 앱은 다음 실행 때 새 버전을 자동으로 받아옵니다.
