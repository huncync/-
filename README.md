# 말이 줄어든 다음 — 「남자들끼리 하는 말」 3권 선주문 페이지

박지훈(@mszexc)의 전자책 3권 「말이 줄어든 다음」 선주문 알림 신청 페이지입니다.
빌드 과정 없이 `index.html`, `style.css`, `script.js` 세 파일로 동작합니다.

## 날짜에 따라 화면이 자동으로 바뀝니다 (한국 시간)
| 기간 | 화면 |
|---|---|
| ~ 11/10 | 선주문 오픈 카운트다운 + 이메일 알림 신청 |
| 11/11 ~ 11/17 | "선주문하기 · 22,000원" 결제 버튼 + 마감 카운트다운 |
| 11/18 ~ | "구매하기 · 29,000원" |

미리 보려면 주소 끝에 `?phase=presale` 또는 `?phase=regular`를 붙이세요.
날짜는 `script.js` 맨 위 `OPEN_AT`, `PRESALE_END`, `SHIP_AT`에서 바꿀 수 있습니다.

## 공개 전에 꼭 할 일
1. **신청 저장 연결 (필수)** — 지금은 테스트 모드라 신청 내용이 저장되지 않습니다.
   https://formspree.io 에서 폼을 만들고 받은 주소를 `script.js`의 `FORM_ENDPOINT`에 넣으세요.
   받은 명단은 CSV로 내려받아 스티비에 올리면 됩니다. 수신동의 시각(`consent_at`)이 같이 저장됩니다.
2. **결제 링크 (11/11 전까지)** — 자체몰·스마트스토어 등의 상품 주소를 `PAYMENT_URL`에 넣으세요.
   비어 있으면 결제 버튼이 "준비 중" 안내를 띄웁니다.

## 무료 배포 (GitHub Pages)
Settings → Pages → Branch를 이 페이지가 있는 브랜치 / `(root)`로 선택하면
몇 분 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소가 생깁니다.
인스타 링크에 붙일 때는 `?utm_source=instagram`처럼 붙이면 신청서에 유입 경로가 같이 저장됩니다.
