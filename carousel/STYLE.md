# 캐러셀 기본 틀 (10/15 확정)

- 크기 1080×1350, 검은 배경(#0b0b0c), 강조색 금색(#e0b46a), 밝은 배경 위 금색은 #8a5a12
- **1장(표지)**: 제목은 굵은 고딕(Noto Sans KR 900, 약 150px), 윗줄 한 줄은 손글씨(나눔펜, 64px)로 다리 놓기, 아래 한 줄 질문
- **2장부터**: 제목은 손글씨(나눔펜, 획 두께 보강), 본문은 Noto Sans KR
- 글씨 최소 크기 34px (휴대폰에서 약 13px)
- 손글씨 제목은 한 줄 12자 안팎, 최대 2~3줄
- 상단 진행 막대("3 / 7"), 반전 장은 크림 배경, 마지막에 요약/결과 장 + 대신 전하는 한 장
- 마지막 줄: "남자가 하는 말의 뜻은 전자책 1·2권에 · 프로필 링크에서 무료"

# 캡션 · 고정 댓글 틀 (10/15 확정, 전체 목록은 plan/captions_plan.md)

- 캐러셀마다 캡션과 고정 댓글을 같이 만든다.
- 캡션 순서: 첫 줄 후크(표지 제목과 다른 문장) → 항목 2~3개만 공개 → "나머지는 넘기면서" → 핵심 한 줄 → 보낼 대상 지정(A: 친구, B: 남자친구, C: "너는 몇 개야?") → 번역 시리즈는 다음 편 예고 + 팔로우 → 전자책 안내 → 해시태그 6개
- 전자책 안내: 평소 1·2권 프로필 링크 / 11/5~11/10 3권 예고 / 11/11~11/17 3권 예약(29,000원, 12/2 발송)
- 고정 댓글: 숫자·한 단어로 답할 수 있는 질문 하나(개수, 유형, '편/식'), B형은 "남자친구 태그"
- 댓글로 전자책 주기, 구독 언급은 쓰지 않는다
