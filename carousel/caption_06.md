# 캐러셀 #05 「남자가 식을 때, 말투보다 먼저 바뀌는 것」 (c06_slide_01~10)

## 캡션
```
말투는 마지막까지 그대로예요.
그래서 더 헷갈리는 거고요.

남자가 식을 때, 말투보다 먼저 바뀌는 것
① 당신이 했던 말을 기억 못 해요
② 만나서 휴대폰을 봐요
③ 통화를 먼저 끊어요
④ 혼자 정하는 게 늘어나요
⑤ 당신 기분보다 자기 피곤함이 먼저예요
⑥ 스토리에서 당신이 사라져요

하나만 보이면 피곤한 거고,
여러 개가 겹치면 그때 이야기해야 해요.

이거 보고 떠오른 친구가 있다면, 지금 보내주세요.

📕 남자가 하는 말의 뜻은 「남자들끼리 하는 말」 1·2권에 적었습니다.
프로필 링크에서 무료로 받아보세요.

#남자심리 #연애심리 #권태기 #남자속마음 #연애고민 #남자들끼리하는말
```
